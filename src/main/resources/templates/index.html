REST API Endpoints & Developer Reference

📥 Download Postman Collection

All backend APIs adhere to RESTful standards, RFC 7807 error responses, JPA user auditing headers (X-User-Id), and Optimistic Concurrency Locking.

GET /api/v1/warehouses

Retrieve all warehouse facilities with capacity and occupancy metrics.

POST /api/v1/warehouses

Register a warehouse. Enforces unique warehouseCode and non-negative capacity.

GET /api/v1/products

List all products. Computes isLowStock dynamically against reorderLevel.

GET /api/v1/products/paged?page=0&size=10

Safe paginated product endpoint preventing server heap exhaustion.

POST /api/v1/stock-movements

Execute atomic STOCK_IN, STOCK_OUT, or ADJUSTMENT with optimistic lock checking.
